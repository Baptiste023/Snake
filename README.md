Ce projet est une reproduction du jeu Snake, développée en Python à l’aide de la bibliothèque Pygame.
Le joueur contrôle un serpent qui grandit en mangeant des pommes.
La partie se termine quand le serpent touche un mur ou son propre corps.

Commandes:

  Flèches directionnelles et zqsd : déplacer le serpent  
  Clic souris : recommencer après un Game Over
