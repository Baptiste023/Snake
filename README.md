# Snake

Le serpent grandit en mangeant des pommes,
la partie se termine sur un mur ou sur son propre corps.

## Comment jouer :
python Snake.py. 
Flèches ou ZQSD pour tourner (le demi-tour direct est bloqué).
Clic souris pour relancer après un game over.

## Spécifications :
Pygame,
un fichier de 155 lignes,
vitesse fixée à 10 images par seconde,
+1 point par pomme,
score affiché à l'écran.
